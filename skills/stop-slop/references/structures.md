# Structural Patterns to Break

## Binary Contrasts

Creates false drama. State Y directly — drop the negation.

| Slop                               | Fix                 |
| ---------------------------------- | ------------------- |
| "Not because X. Because Y."        | "Y."                |
| "X isn't the problem. Y is."       | "Y is the problem." |
| "The answer isn't X. It's Y."      | "Y."                |
| "Not X. But Y."                    | "Y."                |
| "not just X but also Y"            | "X and Y."          |
| "stops being X and starts being Y" | "It becomes Y."     |
| "doesn't mean X, but actually Y"   | "Y."                |

## Negative Listing

Listing what something is not before revealing what it is — a rhetorical
striptease.

| Slop                                             | Fix             |
| ------------------------------------------------ | --------------- |
| "Not a tool... Not a platform... A system."      | "A system."     |
| "It wasn't fast. It wasn't clean. It was right." | "It was right." |

## Dramatic Fragmentation

Sentence fragments for emphasis read as manufactured profundity.

| Slop                                                    | Fix                                |
| ------------------------------------------------------- | ---------------------------------- |
| "Speed. Quality. Cost. That's it. That's the tradeoff." | "Speed, quality, cost — pick two." |
| "X. And Y. And Z."                                      | "X, Y, and Z."                     |
| "This unlocks something. Focus."                        | "This enables focused work."       |
| "[Noun]. That's it. That's the [thing]."                | Write a complete sentence.         |

## Rhetorical Setups

Announce insight rather than deliver it.

| Slop                    | Fix             |
| ----------------------- | --------------- |
| "What if I told you X?" | State X.        |
| "Here's what I mean:"   | Just mean it.   |
| "Think about it:"       | Make the point. |
| "And that's okay."      | Cut it.         |

## False Agency

Giving inanimate things human verbs hides who actually does the thing.

| Slop                            | Fix                          |
| ------------------------------- | ---------------------------- |
| "a complaint becomes a fix"     | "the team fixed it"          |
| "the decision emerges"          | "someone decided"            |
| "the culture shifts"            | "people changed behavior"    |
| "the data tells us"             | name who drew the conclusion |
| "the market rewards"            | "buyers pay for"             |
| "the conversation moves toward" | "someone steers toward"      |

## Narrator-from-a-Distance

Floating above the scene instead of putting the reader in it.

| Slop                           | Fix                                           |
| ------------------------------ | --------------------------------------------- |
| "Nobody designed this."        | "You don't sit down one day and decide to..." |
| "This happens because..."      | Address the reader directly.                  |
| "People tend to..."            | "You might find yourself..."                  |
| "Teams often struggle with..." | "You'll probably hit..."                      |

## Passive Voice

Find the actor. Put them at the front.

| Slop                       | Fix                                 |
| -------------------------- | ----------------------------------- |
| "X was created"            | "The team created X" / "We built X" |
| "It is believed that"      | "We believe that"                   |
| "The decision was reached" | "We decided"                        |
| "Mistakes were made"       | Name who made them                  |

## Sentence Starters to Restructure

| Slop                                                  | Fix                           |
| ----------------------------------------------------- | ----------------------------- |
| Starting with What, When, Where, Which, Who, Why, How | Lead with the subject or verb |
| Paragraphs starting with "So"                         | Start with content            |
| Sentences starting with "Look,"                       | Remove "Look,"                |

"What makes this hard is the constraint" → "The constraint is X" — or better,
name the specific constraint.

## Rhythm Traps

| Trap                           | Fix                                       |
| ------------------------------ | ----------------------------------------- |
| Three-item lists               | Use two items or one                      |
| Em dashes                      | Use commas or periods. No em dashes.      |
| Every paragraph ends punchily  | Vary endings                              |
| Stacked short punchy sentences | Let some sentences breathe                |
| "Not always. Not perfectly."   | Hedging disguised as reassurance — cut it |

## Before/After Examples

### Example 1: Throat-Clearing + Binary Contrast

- Before: "Here's the thing: building products is hard. Not because the
  technology is complex. Because people are complex. Let that sink in."
- After: "Building products is hard. Technology is manageable. People aren't."

### Example 2: Filler + Unnecessary Reassurance

- Before: "It turns out that most teams struggle with alignment. The
  uncomfortable truth is that nobody wants to admit they're confused. And that's
  okay."
- After: "Teams struggle with alignment. Nobody admits confusion."

### Example 3: Business Jargon Stack

- Before: "In today's fast-paced landscape, we need to lean into discomfort and
  navigate uncertainty with clarity. This matters because your competition isn't
  waiting."
- After: "Move faster. Your competition is."

### Example 4: Dramatic Fragmentation

- Before: "Speed. Quality. Cost. You can only pick two. That's it. That's the
  tradeoff."
- After: "Speed, quality, cost — pick two."

### Example 5: Rhetorical Setup

- Before: "What if I told you that the best teams don't optimize for
  productivity? Here's what I mean: they optimize for learning. Think about it."
- After: "The best teams optimize for learning, not productivity."
